# CH-03 Package

Gói phát triển chi tiết của chương ba, Huyết Mộc Đoạt Mệnh.

## Đọc theo thứ tự

1. `00-chapter-brief.md` - mục tiêu, canon lock và end states.
2. `01-scene-flow.md` - flow cảnh từ cổng Phong Châu tới khi tiếng binh khí im.
3. `02-cast-and-factions.md` - nhân vật, boss, vong linh Lạc Việt và hai phe.
4. `03-quests-and-choices.md` - quest, choice, state effect.
5. `04-dialogue-script.md` - thoại chủ đạo và biến thể nhánh.
6. `05-boss-encounter.md` - encounter Mộc Tinh theo phase.
7. `06-state-and-handoff.md` - state machine narrative và handoff liên ngành.
8. `07-validation.md` - checklist nghiệm thu CH-03.
9. `08-visual-design.md` - visual contract cho Mộc Tinh và Tướng Quân Vô Đầu.

## Nội dung đã khóa

- Chapter arc: tiến vào kinh đô bị rừng nuốt -> điều tra lời thề -> lựa chọn số phận vong linh -> boss -> hậu quả.
- Boss fate: `released`, `defeated_by_force`, `absorbed`, `sacrificed`.
- Ba choice chính: `C-CH03-001`, `C-CH03-002`, `C-CH03-003`.
- Mảnh Long Ngọc: `LG-03`.
- Truth flag: `TRUTH_OLD_ARMY_WAS_BOUND`.
- Oan Khuất Ẩn (ADR-004): `HB-03` Tướng Quân Vô Đầu, màn ẩn `CH-03-HIDDEN`, quest `Q-CH03-00H`.
- Visual language: Đông Sơn/Lạc Việt, vật liệu rễ-gỗ-máu, cultural review bắt buộc.

- Thời lượng chính xác từng encounter.
- Combat tuning và số liệu.
- Layout map, model, animation, VFX, SFX cụ thể.
- Cách lưu state trong runtime.
- Vị trí chính xác của hook phụ Nguyên thần Chân Tinh (TBD, không khóa ở CH-03).
