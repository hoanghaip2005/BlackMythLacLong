# CH-01 Package

Đây là gói phát triển chi tiết đầu tiên của Huyết Mạch Lạc Long.

## Đọc theo thứ tự

1. `00-chapter-brief.md` - mục tiêu, canon lock và end states.
2. `01-scene-flow.md` - flow cảnh từ thức tỉnh đến rời biển.
3. `02-cast-and-factions.md` - nhân vật, boss và Thủy tộc.
4. `03-quests-and-choices.md` - quest, choice, state effect.
5. `04-dialogue-script.md` - thoại chủ đạo và biến thể nhánh.
6. `05-boss-encounter.md` - encounter Ngư Tinh theo phase.
7. `06-state-and-handoff.md` - state machine narrative và handoff liên ngành.
8. `07-validation.md` - checklist nghiệm thu CH-01.
9. `08-visual-design.md` - visual contract cho Long Nhân và Ngư Tinh.

## Nội dung đã khóa

- Chapter arc: thức tỉnh -> điều tra -> lựa chọn -> boss -> hậu quả.
- Boss fate: `released`, `defeated_by_force`, `absorbed`.
- Ba choice chính: `C-CH01-001`, `C-CH01-002`, `C-CH01-003`.
- Mảnh Long Ngọc: `LG-01`.
- Truth flag: `TRUTH_SEAL_WAS_NEVER_BROKEN`.
- Visual language: Đông Sơn/Lạc Việt, vật liệu sông biển, cultural review bắt buộc.

## Nội dung chưa khóa

- Thời lượng chính xác từng encounter.
- Combat tuning và số liệu.
- Layout map, model, animation, VFX, SFX cụ thể.
- Cách lưu state trong runtime.
- Tên đầy đủ và backstory sâu của các NPC phụ ngoài CH-01.
- Topology, texture resolution, animation frame và final asset lock.
